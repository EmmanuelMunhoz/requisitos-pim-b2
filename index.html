03 • Integração multidisciplinar

O que cada matéria precisa entregar

Clique em uma disciplina para ver os requisitos vinculados diretamente ao PIM.

C
Núcleo técnico

Programação Estruturada em C

MVP funcional do catálogo de agentes.

⌄
  • Programa em C para gerenciar o catálogo.
  • Até 50 agentes.
  • Campos: ID, nome, script/instruções e nota.
  • Nome: até 80 caracteres; script: até 1000 caracteres; nota: 0 a 5.
  • Menu com cadastrar, listar, buscar por ID, buscar por nome e encerrar.
  • Na busca: exibir dados e permitir editar, excluir ou voltar.
  • Organização em vetores paralelos.
  • Persistência em arquivo: salvar e recuperar registros.
  • Usar condicionais, repetições, funções, arranjos e manipulação de arquivos.
  • Código funcional, comentado, validado e com evidências de teste.
DB
Obrigatório

Modelagem de Banco de Dados e NoSQL

Modelagem completa, mesmo sem o C usar banco agora.

⌄
  • Desenvolver a modelagem do banco de dados.
  • Apresentar o DER.
  • Entregar script SQL de criação.
  • Inserir alguns dados de exemplo.
  • Demonstrar consultas/buscas úteis.
Importante: o documento deixa claro que o software em C não precisa utilizar o banco neste momento.
AG
Obrigatório

Engenharia de Software Ágil

Planejamento, modelagem e qualidade do projeto.

⌄
  • Organizar sprints, backlog e acompanhamento.
  • UML: caso de uso, classes e sequência.
  • Plano de homologação e testes.
  • Manual de uso do sistema.
  • Regras de negócio definidas pelo próprio grupo e aplicadas ao sistema.
LAN
Obrigatório

Redes e Sistemas Distribuídos

Uma possível implantação do sistema em rede local.

⌄
  • Diagrama básico de rede.
  • Especificação de um possível funcionamento em LAN.
  • Indicação de IPs estáticos, DHCP etc.
  • Explorar conceitos de cliente-servidor.
Sem exagero: o texto pede representação/especificação de funcionamento em LAN; não exige transformar o programa C em um sistema de rede funcional.
IA
Evidência

Inteligência Artificial

Registrar como a IA apoiou o desenvolvimento do PIM.

⌄
  • Usar IA no desenvolvimento do PIM.
  • Apresentar evidências das ferramentas utilizadas.
  • Registrar scripts/prompts usados no desenvolvimento do texto/projeto.
Não está exigido no guia: integrar o programa em C a uma API de LLM. O que aparece como mínimo é a evidência de uso de IA no desenvolvimento.
IN
Pesquisa

Pesquisa, Tecnologia e Inovação

Pesquisa aplicada e diferencial do projeto.

⌄
  • O PIM incentiva pesquisa de temas inovadores ligados ao curso.
  • O guia apresenta inovação e criatividade em seus critérios sugeridos.
  • Descrever o diferencial escolhido pelo grupo para o projeto.
Exemplos, não obrigações específicas: tags para localizar agentes e funcionalidades extras de avaliação são sugestões do documento.
EA
Obrigatório

Educação Ambiental

Métricas de sustentabilidade ligadas à digitalização.

⌄
  • Produzir relatório de sustentabilidade.
  • Levantar métricas alcançáveis com a substituição de registros físicos.
  • Aplicar as métricas a um cenário hipotético do sistema.
  • Exemplos citados: redução de papel, economia de água e redução de CO₂.
  • Incluir recomendações de educação ambiental.

06 • Atenção máxima

Riscos críticos para a entrega

Itens com impacto direto na aprovação e na validação do projeto.

!
Não postar no sistema dentro do prazo

O guia informa expressamente que, se o PIM não for postado no sistema acadêmico dentro do prazo, o aluno será reprovado.

!
Plágio

Plágio identificado zera o trabalho para todos os integrantes e grupos envolvidos. O texto também trata plágio integral, parcial, conceitual e autoplágio.

⚠
Ignorar linguagem/tecnologias exigidas

O documento avisa que trabalhos que não atendam aos itens de linguagem e tecnologias descritos podem ser reprovados.

⚠
ABNT mal feita

A tabela sugerida alerta que trabalhos fora do formato ABNT poderão ser reprovados sumariamente.

i
Máximo de 8 integrantes

Conforme orientação atual da coordenação do curso. O grupo deve participar dos encontros definidos pelo orientador.

i
Nota pode variar por integrante

A nota final é definida pelo orientador e pode ser diferente para cada aluno conforme a participação ao longo do semestre.
